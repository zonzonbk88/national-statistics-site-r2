ThaiStat — Thailand in Numbers: an original national statistics site for the make.fun bounty. Overview, Economy, People, Trade & Tourism, a searchable/sortable Provinces table and a Data Explorer (14 indicators with year ranges and CSV download). Every figure carries its source and year; charts are hand-rolled SVG; fully static, no network.
